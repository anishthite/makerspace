Decisions

IDChoice · Rationale
D-001Reuse sessions as threads. One JSON store already captures repo, VM, bridge, and run state.
D-002Use /thread.html?name=... instead of router fallback. Static server stays boring.
D-003Thread prompts run sequentially on the same bridge VM. Avoid multiplexing one Pi bridge.
D-004Vercel serves only static UI. DigitalOcean keeps the current SSH/spawn/SSE control process intact.
D-005Add CORS plus a single optional bearer token. No accounts yet, but public VM-spinning endpoints are not left open when CONTROL_API_TOKEN is set.

Tradeoffs

IDPicked over Rejected · Reason
T-001Existing SSE bridge over terminal emulation. It mirrors Pi input/output with fewer moving parts.
