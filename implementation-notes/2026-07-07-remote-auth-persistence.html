Remote auth persistence

main · worktree /Users/anishthite/workspace/makerspace · 2026-07-07 · status shipped · blast high

Summary

Goal
Stop remote users from redoing Codex OAuth refresh and GitHub CLI auth during normal bridge reuse.
Source
User reports remote sign-in prompts every few minutes for both Codex and GitHub.
Surface
Bridge /auth, backend auth store, sandbox gh config.
Schema
Reuses existing encrypted per-user secret records.
Open Qs
0.

Algorithm

  1. Bridge GET /auth returns current remote auth.json to the backend only.
  2. When a bridge run reaches terminal status, backend reads remote auth and writes valid provider OAuth credentials back to encrypted user secrets.
  3. Bridge POST /auth still seeds Codex/Claude auth before each run.
  4. Bridge GitHub sync writes ~/.config/gh/hosts.yml alongside ~/.git-credentials.
