Summary

Goal
Resume suspended Cloudflare threads without loading backup archives into the Durable Object isolate.
Source
User report: Durable Object's isolate exceeded its memory limit during send-to-resume.
Surface
cloudflare-sandbox-worker/src/index.js backup and restore broker routes.
Schema
No stored schema change; legacy backup handles may keep localBucket:true.
Open Qs
0.

Algorithm

  1. Default broker backup calls to SDK production mode by omitting localBucket.
  2. Allow localBucket:true only from explicit request body or LOCAL_DEV.
  3. Strip legacy localBucket:true during production restore so presigned R2 transfer handles old suspended sessions.

Decisions

IDChoice · Rationale
D-001Use SDK production backup mode by default. The SDK streams archive transfer through presigned R2 URLs instead of DO memory.
D-002Keep LOCAL_DEV as the local-bucket switch. Local dev can avoid R2 API secrets without affecting deployed workers.

Tradeoffs

IDPicked over Rejected · Reason
T-001Broker default change over app-level resume special case. All suspend, delete, and resume callers share the same memory-safe path.

Assumptions

  • A-001 · Production worker has or can set CLOUDFLARE_R2_ACCOUNT_ID or CLOUDFLARE_ACCOUNT_ID, plus R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, and BACKUP_BUCKET_NAME. If wrong: backup fails clearly instead of OOMing.
