Thread link rendering

main · worktree /Users/anishthite/workspace/makerspace · 2026-07-16 · status shipped · blast low

Summary

Goal
Make thread assistant links clickable without turning whole messages into a Markdown renderer.
Source
User asked for external links, code links, and similar link targets to render.
Surface
frontend/src/runtime/thread.js, frontend/src/runtime/openui-renderer.jsx, link styling, focused static tests.
Schema
No stored data or API shape change.
Open Qs
0; allow only known URL schemes.

Algorithm

  1. Parse text nodes for Markdown links, bare http(s) URLs, and explicit code-editor schemes.
  2. Render safe targets as anchors with target="_blank", rel="noopener noreferrer", and a link-kind class.
  3. Handle OpenUI open_url actions by opening the URL instead of filling the composer.
