Algorithm

  1. Keep the default recent list capped at six rows.
  2. When search text exists, match every accepted recent project by label, value, source, and branch tokens.
  3. Show up to twelve search matches and keep each button’s original recent-project index.

UI layout

  1. Search: put one native type="search" input at the top of the popup.
  2. Projects: keep the existing recent project rows and badges.
  3. Project picker: place a footer link labeled Browse all projects instead of return home.
