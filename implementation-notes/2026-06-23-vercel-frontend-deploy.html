Decisions

IDChoice · Rationale
D-001Use the existing static vercel.json and skip install. npm run build only copies public/ to dist/.
D-002Keep the control backend off Vercel. Daytona credentials and long-running SSE belong on the separate Node backend.
D-003Add .vercelignore before deployment. Local .env contains deploy-irrelevant secrets.

Tradeoffs

IDPicked over Rejected · Reason
T-001.vercelignore over a new frontend/ package. Smaller diff and no copied assets.
T-002Static Vercel deploy over serverless API routes. The browser already supports a remote control backend URL.

Assumptions

  • A-001 · The current Vercel login and default scope are acceptable. If wrong: redeploy under the chosen scope.
  • A-002 · A separate HTTPS control backend will be configured after frontend deploy. If wrong: the UI loads but API actions fail until configured.
