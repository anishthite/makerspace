IDChoice · Rationale
D-001Delete wrappers with zero reachability from non-UI frontend roots. Keeping scaffold for later violates ponytail YAGNI.
D-002Keep live wrappers only. sidebar, sheet, form controls, and toast surfaces are still imported.
D-003Keep demo-route and build-asset dependency cuts out of this patch. Those affect route availability and CSS build inputs.

D-007Remove dead JSX-only React namespace imports. Vite's React plugin handles the automatic JSX runtime.
