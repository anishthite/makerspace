Bridge URL diagnostics

main · worktree /workspace · 2026-07-14 · status shipped · blast low

Summary

Goal
When a run reaches a missing bridgeUrl, show the last Cloudflare launch/port-expose failure instead of only the generic missing URL text.
Source
User hit No bridge URL is available for makerspace-... and asked for future diagnostics.
Surface
Cloudflare provider launch logs and bridge base URL errors.
Schema
No new fields; uses existing bridgeLaunchLog, bridgeLaunchStage, and warning.

Files

PathDelta
src/providers/cloudflare.jsEmit launch phases for session creation, restore, setup, and port_expose; persist the port-expose failure message.
src/server/bridge.jsAppend last launch stage/error to missing bridge URL exceptions.

test/bridge-auth-sync.test.jsPin enriched missing bridge URL error text.

Decisions

IDChoice · Rationale
D-001Use existing onLaunchLog plumbing. It already redacts sensitive fields and writes to the session row.
D-002Store host-only bridge success detail, not the full URL. Enough for debugging without noisy/raw bridge links.
D-003Keep the generic prefix but append diagnostics. Existing callers/tests can still identify missing URL errors.
