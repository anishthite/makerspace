Cloudflare startup retry

main · worktree /Users/anishthite/workspace/makerspace · 2026-07-13 · status shipped · blast low

Summary

Goal
Retry broker responses that clearly mean Cloudflare is still starting the sandbox.
Source
@cloudflare/sandbox returns startup/provisioning messages during container boot.
Surface
src/providers/cloudflare.js broker calls and provider tests.
Schema
None.
Open Qs
0.

Algorithm

  1. Read broker or bridge-port error text and classify only startup/provisioning phrases as retryable.
  2. Sleep from Retry-After when present; otherwise use capped exponential backoff.
  3. Stop broker retries after cloudflareBrokerRetryAttempts or cloudflareBrokerRetryTimeoutMs/bridgeReadyTimeoutMs; stop bridge-port retries after bridgeReadyTimeoutMs.
