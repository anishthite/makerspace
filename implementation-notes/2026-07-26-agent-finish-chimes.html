Summary

Goal
Play the spark chime when an active agent transitions to finished.
Source
Existing finish-toast transition in app.js and agent-toasts.js.
Surface
/workspace.html, non-workspace pages, and /chimes.html.
Schema
Add localStorage key spannerCompletionChime.
Mobile
Preview uses wrapping buttons; runtime audio is UI-free.
Open Qs
0; spark is the only valid chime.

Algorithm

  1. Detect a finish transition only when previous status is active and next status is completed, ready, or failed.
  2. Show the existing toast and call playCompletionChime() once per finish key.
  3. Build tones with AudioContext, short oscillator envelopes, and silent fallback when autoplay blocks playback.

UI layout

  1. Preview: /chimes.html lists chime variations with play and select buttons.
  2. State: selected variation writes spannerCompletionChime and is reused by finish toasts.
