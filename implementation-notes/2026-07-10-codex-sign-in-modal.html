Decisions

IDChoice · Rationale
D-001Do not add a query-param prefill. Codex source returns only {base}/codex/device, and live navigation strips tested code-like query params before OAuth.
D-002Use native <dialog>. It avoids a new dependency and already matches the repo's full-diff modal pattern.
D-003Use the existing auth-steps rows for Codex. It creates the requested two-step framing without a new component.
D-004Use the existing shadcn-wrapped Button with Phosphor icons. No dedicated copy-code component exists in the local shadcn set.
D-005Keep micro-polish in CSS. Header scale, close chrome, step spacing, and copy-button placement need no new component.
D-006Make the verification URL a text link and embed the copy button in the code box. This fixes alignment without adding layout chrome.

Tradeoffs

IDPicked over Rejected · Reason
T-001User-clicked new tab over reserved blank tab. The click avoids popup blocking without leaving a blank tab during API startup.
