Summary

Goal
Show generated follow-up prompt suggestions below completed thread output.
Source
Post-run polish completion over taskPrompt and the latest assistant answer.
Surface
/thread.html, suggested_next_steps stream event, session JSON.
Schema
Add optional suggestedNextSteps* session fields.
Open Qs
0; assume bottom means above the composer.

API contract

Session fields

{
  suggestedNextSteps: [{ label: string, prompt: string }],
  suggestedNextStepsRunId: string,
  suggestedNextStepsModel: string,
  suggestedNextStepsUpdatedAt: string
}

Stream event

{
  type: "suggested_next_steps",
  steps: [{ label: string, prompt: string }],
  session: Session
}

Algorithm

  1. After the assistant message is persisted, enqueue one next-step generation job per name:runId.
  2. Ask for JSON with steps[].label and steps[].prompt; cap at three suggestions.
  3. Store suggestions only if the latest stored run still matches runId.

UI layout

  1. Suggested next steps: render a bottom card above the composer when suggestedNextSteps is non-empty.
  2. Step button: show label plus prompt preview; click fills the composer without auto-sending.
