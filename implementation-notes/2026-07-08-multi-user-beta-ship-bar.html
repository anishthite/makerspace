API contract

WORKBENCH_ALLOWED_USERS=octo,mona,github-123
# Empty value keeps existing GitHub-auth behavior.
# Non-empty value allows matching GitHub login, githubId, or stored user id only.

Algorithm

  1. Keep stale active rows failed for list/archive surfaces.
  2. Use persisted bridge status only for active control actions: stop, steer, followUp.
  3. Deny GitHub OAuth callback before user/token persistence when WORKBENCH_ALLOWED_USERS excludes the account.
  4. Keep broad usage deferred behind allowlist until quotas/billing exist.

Decisions

IDChoice · Rationale
D-001Use WORKBENCH_ALLOWED_USERS over billing or roles. Private beta needs a gate, not an account system.
D-002Reject excluded users before persistence. Denied accounts should not create users, auth sessions, or OAuth token rows.
D-003Trust stored bridge status for control actions only. List/archive should still surface stale active rows as failed.
D-004Write launch:failed before the warning. Tests and users should not see failed state before its diagnostic phase exists.

IDPicked over Rejected · Reason
T-001Env allowlist over Cloudflare Access-only. The app can enforce the beta gate even when the operator skips the proxy layer.
T-002Route manifest update over generator work. Existing test already detects drift.
