Decisions

IDChoice · Rationale
D-001Use localhost over 127.0.0.1. GitHub OAuth app callbacks are configured with the hostname string.
D-002Use fixed Electron port 8788 over a random free port. OAuth callback registration cannot follow per-launch ports.
D-003Keep hosted deployment ports env-driven. Production containers and droplets already set PORT.

Tradeoffs

IDPicked over Rejected · Reason
T-001Fail on occupied desktop port over fallback to another port. Fallback would recreate the OAuth redirect mismatch.

Reversibility

R-001 · medium. Restore 8787, 127.0.0.1, and random Electron ports if GitHub OAuth supports those registered callbacks.

Definition of done

  • Default backend config reports port 8788.
  • Local-provider config reports host localhost.
  • Desktop loads and protects http://localhost:8788.
  • Desktop reports an occupied local port before quitting.
  • Focused auth/startup tests pass.
