Bridge run reattach

main · worktree /Users/anishthite/workspace/makerspace · 2026-07-12 · status ready-for-review · blast medium

Summary

Goal
Recover active Cloudflare bridge runs after the DigitalOcean Node process loses activeRuns.
Source
Stored session fields plus bridge /runs/:id/stream.
Surface
/api/bootstrap?page=thread, /api/threads, /api/threads/:name, startup hook.
Schema
No new fields; reuse bridgeUrl, bridgeRunId, bridgeToken, bridgeClaimed.
Storage
Keep persisted session status authoritative; keep activeRuns as a live cache.
Open Qs
0.

Algorithm

  1. Identify reattachable sessions with active stored status and complete bridge connection fields.
  2. Create or reuse the live run cache and seed runStatus from the stored status.
  3. Start followBridgeRun() from startup, thread listing, thread load, and output sync.
  4. Let existing stale-run handling mark missing bridge runs failed only after bridge stream failure.
  5. Show stale-copy only when no reattachable bridge fields exist or the bridge follower terminalizes the run.
