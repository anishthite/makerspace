LLM workspace suggestions

Summary

Goal
Make /workspace.html launch suggestions LLM-generated without reading suggestedNextSteps.
Source
Selected-project threads posted by the browser with title, task, final summary, status, and blocker fields.
Surface
POST /api/workspace-suggestions and #launch-suggestions.
Schema
No stored-data change; response is { suggestions: [{ label, prompt }] }.
Fallback
Keep static starter prompts while generation is pending or unavailable.
Open Qs
0.

API contract

POST /api/workspace-suggestions
{ threads: [{ title, taskPrompt, initialPrompt, finalAnswerSummary, finalTurnStatus, finalTurnReason, status, runStatus, warning, finishedAt }] }
{ suggestions: [{ label: string, prompt: string }] }

Algorithm

  1. Browser sends up to six selected-project inactive thread summaries after thread list render.
  2. Server caps text fields and calls WORKSPACE_LAUNCH_SUGGESTIONS_MODEL.
  3. Model returns two or three workspace starter prompts as JSON; existing cleaner dedupes and caps to three.
  4. Browser renders returned prompts or leaves static fallback.
