Compact full diff view

main · worktree /Users/anishthite/workspace/makerspace · 2026-07-04 · status shipped · blast low

Summary

Goal
Keep the sidebar changes box small and open a full diff dialog with diff2html only when requested.
Source
Existing GET /api/threads/:name/diff payload.
Surface
/thread.html changes rail and <dialog>.
Schema
No API or persisted data change.
Mobile
Dialog width clamps to viewport and scrolls horizontally for side-by-side tables.
Open Qs
0; use modal rather than replacing the rail.

Algorithm

  1. Render the rail as the existing selected-file text preview.
  2. Store the latest diff payload from /diff.
  3. Open #diff-dialog from the preview or the explicit open button.
  4. Render all files or a selected file; lazy-load diff2html for unified diffs and use escaped <pre> for plain previews.

Decisions

IDChoice · Rationale
D-001Use a native <dialog>. It avoids adding modal plumbing.
D-002Lazy-load diff2html. The package cost is paid only when opening full diffs.
D-003Keep the rail plain. Side-by-side diff tables need full width.
D-004Override diff2html color variables in the dialog. The default light table clashes with the thread UI.
D-005Use a left file rail and line-by-line diff in the dialog. It avoids nested side-by-side horizontal scrolling.

Tradeoffs

IDPicked over Rejected · Reason
T-001Full dialog over sidebar replacement. The renderer needs width and the rail should stay lightweight.
T-002diff2html over @git-diff-view/react. It matches unified diff payloads with less runtime cost.
T-003App file chips over diff2html file list. One file switcher is cleaner.
T-004Line-by-line full diff over side-by-side. Sticky line numbers and a single scroll axis feel better here.
