Decisions

IDChoice · Rationale
D-001Add a standalone route. The current thread runtime stays untouched.
D-002Use selected source primitives over the full AI SDK component set. A demo should not force a backend transport rewrite.
D-003Use existing @phosphor-icons/react icons. The repo already standardizes shadcn output on Phosphor.
D-004Scope demo CSS under .chat-demo. The app has broad h1 and button:not(...) rules that distorted the first pass.
D-005Supersedes D-002 layout use: model the page after assistant-ui Thread primitives. The user asked for a closer Conductor/ChatGPT approximation.
D-006Supersedes D-005 visual density: use the attached dark transcript reference. The card-based plan/tool/terminal treatment remained too component-demo-like.

Tradeoffs

IDPicked over Rejected · Reason
T-001Phosphor icon adaptation over adding lucide-react. The demo keeps dependency churn at zero.
T-002Mocked interval state over a fake SSE route. The goal is visual evaluation, not protocol testing.
T-003Local mock shell over installing @assistant-ui/react. The library is the better full implementation target, but a demo route should not add runtime state dependencies.
T-004Transcript-native tool rows over AI Elements cards. The screenshot’s quality comes from restraint and message rhythm.
