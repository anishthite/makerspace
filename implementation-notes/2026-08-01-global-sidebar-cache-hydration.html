Summary

Goal
Stop the agent sidebar from flashing empty/loading state during normal page opens.
Source
User reported unnecessary sidebar loading when opening a page.
Surface
/, /workspace.html, /thread.html, /history.html, /settings.html, /performance.html.
Storage
localStorage.spannerGlobalSidebarThreadsCache stores sanitized render fields only.
Schema
No server API or durable backend data change.

Algorithm

  1. Write sanitized thread-list rows into spannerGlobalSidebarThreadsCache after successful thread-list bootstrap or refresh.
  2. On first sidebar mount, render cached rows when present.
  3. Fetch /api/threads normally and replace rows only when the existing render signature changes.
