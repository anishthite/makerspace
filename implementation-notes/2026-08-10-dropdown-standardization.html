Decisions

IDChoice · Rationale
D-001Use one app Select wrapper over raw native selects. It centralizes visible dropdown behavior while preserving DOM contracts.
D-002Style active surfaces in place. This avoids rewriting DOM event bridges and native select mutation code.
D-003Use direct paper/rule/blue-soft styling instead of dropdown-only tokens. Supersedes the first token pass after user feedback.
D-004Wrap visible selects with Radix and keep hidden native select nodes. Runtime project and model code keeps existing DOM contracts.
D-005Override prompt trigger chrome in route CSS. Tailwind utility order can leave the base Shadcn border visible.

Tradeoffs

IDPicked over RejectedReason
T-001Hidden native bridge over runtime rewrite.Existing submit and option mutation code stays small.
T-002Grouped selector over token taxonomy.The model picker already defines the useful primitives: paper, rule, and blue-soft.
T-003MutationObserver bridge over runtime rewrite.Runtime can continue setting option nodes and value.
