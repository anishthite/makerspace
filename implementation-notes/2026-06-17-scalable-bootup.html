Decisions

IDChoice · Rationale
D-001Default warm pool to 0. Idle reuse scales with active users instead of reserving capacity for idle traffic.
D-002Reuse completed bridge sessions for IDLE_BRIDGE_TTL_MS. It preserves subsecond follow-up prompts without a permanent pool.
D-003Keep explicit warm pool as an opt-in. Benchmarks and demos can still prewarm when requested.
D-004Keep private registry auth out of data/settings.json. Environment auth avoids committing tokens.

Tradeoffs

IDPicked over Rejected · Reason
T-001Idle TTL over always-on pool. Capacity follows recent activity.
T-002Baked image over setup-time npm installs. Cold path drops dependency installation from launch.

Reversibility

R-001 · medium. Set IDLE_BRIDGE_TTL_MS=0 and WARM_BRIDGE_POOL_SIZE=0 to return to fresh VM per prompt.
