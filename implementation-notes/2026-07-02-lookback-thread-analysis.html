Summary

Goal
Add review score, signal mix, and trace-derived per-thread stats to local telemetry.
Source
pi-lookback/src/summary.js and pi-lookback/src/signals.js heuristics, adapted to Makerspace pi-sessions/*.jsonl.
Surface
GET /api/threads/performance?source=local, /local-telemetry.html.
Schema
None; read-only JSONL parsing.
Mobile
Existing horizontal telemetry table scroll.
Open Qs
0.

Algorithm

  1. Read ${PI_SESSION_TRACE_DIR}/${session.name}.jsonl for local-source rows when present.
  2. Count users, assistants, tools, failed tools, bash, compactions, switches, tokens, cost, models, and parent branches.
  3. Detect pi-lookback signals: failed tools/bash, repeated failures, user corrections, long no-tool stretches, high cost, branch/compaction heavy, huge/truncated output, aborted assistant, and missing verification.
  4. Compute reviewScore = failedTool*4 + failedBash*6 + branch*5 + compaction*3 + min(40, floor(cost*100)) + parseErrors*10 + largeSessionBonus.
