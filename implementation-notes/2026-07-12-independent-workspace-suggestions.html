Make /workspace.html launch suggestions distinct from per-thread follow-up buttons.

Recent finished thread title, task prompt, final summary, final turn status, and run status.

#launch-suggestions below the workspace composer.
Schema
No API or stored-data change.

0.

Algorithm

  1. Sort inactive threads by finishedAtMs descending.
  2. Build one workspace-level prompt per thread from title, finalAnswerSummary, taskPrompt, finalTurnStatus, and status.
  3. Choose Debug for failed threads, Unblock for waiting-on-human, Verify when the summary mentions tests/checks, otherwise alternate Review and Continue.
  4. Deduplicate by generated prompt and render up to three suggestions.
