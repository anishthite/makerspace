Summary

Goal
Let users hide completed agents from / without deleting their thread history.
Source
User asked to archive agents when they are done.
Surface
POST /api/threads/:name/archive, /api/threads, /.
Schema
Add optional archivedAt timestamp to stored thread sessions.
Open Qs
0.

API contract

Request

POST /api/threads/:name/archive

Response

{
  provider: ProviderInfo,
  thread: Session
}

Algorithm

  1. Reject archive unless threadBridge exists, access passes, and runStatus || status is completed.
  2. Set archivedAt = now and updatedAt = now via the existing store write queue.
  3. Filter archivedAt threads out of the home /api/threads payload.

UI layout

  1. Add one archive button to completed thread cards.
  2. Keep clicking the rest of the card as the thread link.
