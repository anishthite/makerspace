Algorithm

  1. createProvider() selects an adapter from config.provider.
  2. Business logic calls generic methods: createSession(), setShare(), destroySession(), readOutput(), runRemoteScript(), bridgeHeaders(), shouldRefreshSession().
  3. Daytona adapter maps generic calls to SDK create/list/get/start/delete, preview links, process, and filesystem APIs.
  4. Thread prompts older than provider refresh policy rerun createSession() before posting to the bridge.
