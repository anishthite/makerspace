Summary

GoalDeliver the local four-tool coding harness.
ProviderDirect OpenAI-compatible streaming HTTP.
LimitsUncapped rounds by default; bounded tool output and command timeout.

Algorithm

  1. Stream and append assistant messages.
  2. Execute tools sequentially and append recoverable results.
  3. Return on no calls; optionally request a final no-tools answer at the cap.

UI layout

  1. Viewport transcript with streamed text and tool rows.
  2. Textarea composer; Ctrl-C cancels and Ctrl-D exits.
