Summary

Goal
Keep bridge launches alive when exe.dev reports a VM before SSH accepts commands.
Source
Screenshot shows Connection to *.exe.xyz closed by remote host immediately after VM ready.
Surface
src/server.js, src/provider.js, test/provider.test.js.
Failure point
seedRemotePiAuth() runs before waitForBridge().

Algorithm

  1. Classify closed by remote host as a transient SSH readiness error.
  2. Retry only transient auth-seed SSH failures until PI_BRIDGE_READY_TIMEOUT_MS.
  3. Throw non-transient SSH errors immediately.
