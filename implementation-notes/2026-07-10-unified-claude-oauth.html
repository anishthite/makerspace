API contract

GET /api/auth/claude-code
POST /api/auth/claude-code/login
GET /api/auth/claude-code/login/:id
POST /api/auth/claude-code/login/:id/code { code: "code#state" | callbackUrl }

Algorithm

  1. startClaudeCodeLogin() always builds the Spanner-owned PKCE authorize URL.
  2. Submitted code exchanges against https://platform.claude.com/v1/oauth/token.
  3. Hosted mode stores the credential in the per-user encrypted secret.
  4. Local mode stores the same credential via AuthStorage.create().set("anthropic", credential).
