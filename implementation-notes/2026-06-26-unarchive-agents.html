Unarchive agents

main · worktree /Users/anishthite/workspace/makerspace · 2026-06-26 · status shipped · blast low

Summary

Goal
Let an archived thread agent be restored from history so /api/threads shows it in the workspace pane again.
Source
User asked for an unarchive control to bring the agent back to the main pane.
Surface
POST /api/threads/:name/unarchive, /history.html, /workspace.html thread lanes.
Schema
No new fields; clear existing archivedAt.
Mobile
Reuse existing history card wrapping.
Open Qs
0; assume “main pane” means the workspace agent lanes filtered by /api/threads.

API contract

Request

POST /api/threads/:name/unarchive

Response

{ provider: ProviderInfo, thread: Session }

Algorithm

  1. Require access to the existing threadBridge session.
  2. Remove archivedAt and bump updatedAt.
  3. Reload history; the workspace list includes the restored agent through the existing !archivedAt filter.

UI layout

  1. History card: show restore to workspace only on archived thread agents.
