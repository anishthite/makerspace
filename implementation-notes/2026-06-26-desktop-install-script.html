Summary

Goal
Install the local Makerspace.app or .dmg into /Applications.
Source
output/desktop-package/Makerspace.app, output/desktop-package/makerspace.dmg, or an explicit path.
Surface
npm run desktop:install and scripts/install-desktop-app.sh.
Schema
None.
Open Qs
0.

Algorithm

  1. Use the explicit path when provided; otherwise prefer the built .app before the .dmg.
  2. Mount .dmg files with hdiutil attach -nobrowse -readonly and find the first nested .app.
  3. Replace /Applications/<App>.app with ditto, using sudo only when the destination is not writable.
  4. Detach the mounted image on exit.
