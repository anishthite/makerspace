Local GitHub Repo Additive

agent-ui-components · worktree /Users/anishthite/conductor/workspaces/makerspace/tripoli · 2026-08-01 · status ready-for-review · blast medium

Summary

Goal
Local provider mode accepts local folders and selected GitHub repos.
Source
/api/github/repos supplies repo choices; git clone materializes them under local state.
Surface
/, /workspace.html, POST /api/threads.
Schema
No persisted schema change; sessions keep repoUrl plus local repoPath.
Open Qs
0.

Algorithm

  1. When provider.kind === "local" and repoMode === "git", clone or fetch into <localDataDir>/repos/github/<owner>/<repo>.
  2. Pass repoAuthHeader only through git -c http.extraHeader=...; persist sessions with repoAuthHeader: "".
  3. Run the existing local Pi path with localMode: true, repoPath, and preserved repoUrl.
