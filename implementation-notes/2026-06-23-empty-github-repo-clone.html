Summary

Goal
Let setup continue when GitHub reports default_branch=main but the repo has no branches yet.
Source
https://github.com/anishthite/buildspace-balls.git has no remote heads; branch clone fails.
Surface
src/setup-script.js, test/setup-script.test.js.
Schema
None.
Open Qs
0.

Algorithm

  1. Try the requested branch clone first.
  2. If it fails, remove the partial workspace and retry a plain shallow clone.
  3. Keep GIT_TERMINAL_PROMPT=0 exported once so both clone attempts stay non-interactive.
