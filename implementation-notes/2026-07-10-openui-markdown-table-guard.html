Algorithm

  1. Keep explicit openui fences authoritative.
  2. When no fence renders, scan outside fenced code blocks for | header |, divider, and data rows.
  3. Emit root = Table([Col(...)]) plus column arrays and strip the original Markdown table from visible text.
