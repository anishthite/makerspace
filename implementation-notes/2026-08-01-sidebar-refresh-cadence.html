Summary

Goal
Reduce sidebar visual refreshes while preserving current agent status updates.
Source
User reported the sidebar update feels weird and refreshes too often.

Open Qs
0.

Algorithm

  1. Build a sidebar signature from row fields plus local search, scope, settled, seen, and current-route state.
  2. Skip innerHTML replacement when the signature is unchanged.
  3. Update active runtime labels at minute granularity on a slower timer.
  4. Route sidebar-owned thread payloads through toast notification state instead of running a second thread poller.
