Algorithm

  1. Prevent default browser file navigation on composer drag events.
  2. On drop, keep accepted image files and append them to the hidden input[type=file].
  3. Update the existing attachment status text.

UI layout

  1. Composer: add a blue dashed outline while an image drag is over the drop zone.
