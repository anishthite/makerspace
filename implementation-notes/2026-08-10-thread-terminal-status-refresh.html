Summary

Goal
Make an open terminal /thread.html page notice when its thread becomes active again.
Source
User reports completed to working does not update automatically.
Surface
/thread.html runtime status pill, controls, history, and SSE attach.
Schema
No API or stored data change.
Open Qs
0.

Algorithm

  1. Every THREAD_STATUS_POLL_MS, skip when hidden, already streaming, or current thread is not terminal.
  2. Fetch GET /api/threads/:name and render the returned thread.
  3. If the refreshed status is active, reset the stale SSE cursor and reopen the stream with streamRun().
