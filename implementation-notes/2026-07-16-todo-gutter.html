Open Qs
0.

Algorithm

  1. On a completed todo tool event, normalize details.tasks into {tasks,nextId,updatedAt}.
  2. Store the snapshot on the active run and upsert session.todoState for reloads.
  3. Render non-deleted tasks sorted by in_progress, pending, then completed.

UI layout

  1. Todo rail: show done/total in the rail head and up to eight task rows.
  2. Task row: show status dot, #id, subject, and active form only for in_progress.
  3. Empty state: hide the rail when there are no non-deleted tasks.
