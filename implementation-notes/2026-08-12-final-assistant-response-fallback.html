Emit a finalized response when that assistant message has no text deltas.

Algorithm

  1. Reset the streamed flag at each assistant message_start.
  2. Emit the finalized text at message_end only when that message emitted no text delta.
  3. Use later fallbacks only when they identify a different finalized message.
