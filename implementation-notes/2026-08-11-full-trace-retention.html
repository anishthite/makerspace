Summary

Goal
Keep all local sanitized trace events without restoring terminal activeRuns retention.
Source
User requested complete durable traces; the existing local compactor removed events beyond 2,000.
Surface
Local JSONL trace files and GET /api/sessions/:name/output.
Schema
Append-only JSONL; normal output returns recent events and explicit traceLimit widens the read.
Open Qs
Cloud D1 remains bounded because its single-KV trace format lacks segment storage.

API contract

GET /api/sessions/:name/output?traceLimit=all
// normal request: newest 2,000 durable trace events
// traceLimit=N: newest N durable trace events
// traceLimit=all: complete local durable trace history

Algorithm

  1. Append each sanitized local event to its existing JSONL file; never compact that file.
  2. Read the tail of the file until the requested number of complete JSONL records is found.
  3. Parse only that tail for normal output; parse the complete file only after explicit traceLimit=all.

Decisions

IDChoice · Rationale
D-001Keep append-only local JSONL over event-count compaction. Durable trace history remains complete.
D-002Tail-read normal output over whole-file reads. Reopening an old thread does not materialize its whole trace.
D-003Expose traceLimit=all without a UI control. The expensive history read is explicit; current timeline behavior stays small.
