Summary

Goal
Expose GitHub auth to the sandbox agent for authenticated git, gh, and API commands.
Source
User accepted full sandbox GitHub access for now.
Surface
Bridge POST /auth accepts githubToken.
Storage
Token lives in bridge process env; gitconfig stores only an env-backed helper.
Blast
High: agent shell can read and use the GitHub OAuth token.

Algorithm

  1. Backend resolves the session owner's GitHub OAuth token before bridge auth sync.
  2. Bridge /auth sets GITHUB_TOKEN and GH_TOKEN in process.env.
  3. Bridge configures credential.https://github.com.helper to emit $GITHUB_TOKEN for git HTTPS auth.
  4. Bridge disposes warmed Pi sessions after auth changes so new agent services inherit env.
