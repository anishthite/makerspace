UI layout

  1. Rows: add a compact selection control before each sidebar agent row.
  2. Selection bar: show selected count plus Settle and Clear actions when selection exists.
  3. Lane tools: add a quiet select action for all visible unsettled settleable rows.
  4. Shortcuts: support Cmd/Ctrl-click toggle and Shift-click range selection.

Decisions

IDChoice · Rationale
D-001Keep selection transient and visible-scoped. Filter changes cannot leave hidden rows selected for accidental actions.
D-002Batch settle only eligible selected threads. Running or already settled rows stay untouched by the settle action.
D-003Use row buttons instead of exposing raw checkboxes. The sidebar keeps the T3-style compact row rhythm.

Tradeoffs

IDPicked over Rejected · Reason
T-001Visible batch bar over context-menu-only actions. The user can discover batch settle without learning hidden gestures.
T-002No batch delete/stop in this pass over shipping every possible bulk action. Destructive and live-agent actions need stricter confirmation copy.
