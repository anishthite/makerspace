Summary

Goal
Render automatic line icons for project rows instead of letter avatars.
Source
Stable hash of project.value, falling back to project.label.
Surface
Project recents, workspace switcher, project lightbox, and global agent sidebar project marks.
Schema
None.
Mobile
Same 16px inline SVG inside existing rows.
Open Qs
0.

Algorithm

  1. Collect names from PROJECT_ICON_PATHS.
  2. Hash project.value || project.label || project.kind || 'project' with hash = hash * 31 + charCode.
  3. Pick PROJECT_ICON_NAMES[hash % PROJECT_ICON_NAMES.length].

UI layout

  1. Recents: insert a 16px project icon before the project title.
  2. Switcher: insert the same icon before the workspace switcher and lightbox row title.
  3. Sidebar: replace letter avatar SVG content with the shared icon renderer.
