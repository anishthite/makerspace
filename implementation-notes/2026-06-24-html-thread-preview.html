Summary

Goal
Render assistant HTML output as a sandboxed designed preview instead of raw escaped text.
Source
Assistant transcript chunks from /api/sessions/:name/output and /stream.
Surface
/thread.html, homepage design prompt suggestion.
Security
iframe sandbox="allow-same-origin"; no allow-scripts.
Schema
None.
Mobile
Preview frame width follows the thread card.
Open Qs
0.

Algorithm

  1. Trim assistant text and unwrap a full ```html fence.
  2. Classify as HTML when it starts with <!doctype html, <html, or a known semantic tag fragment.
  3. Render HTML in a sandboxed srcdoc iframe; render all other content as text.

UI layout

  1. Assistant text: keep the existing bubble and whitespace-preserving text.
  2. HTML preview: widen the assistant card, add a labelled preview rail, and auto-size the frame within a cap.
  3. Prompt shortcut: make the homepage design shortcut ask for hierarchy, spacing, responsive states, and one interaction.
