UI layout

  1. Inline card: iframe requests mode=preview and displays a static exported SVG cropped to element bounds.
  2. Full viewer: open keeps the interactive Excalidraw pan/zoom view.
  3. Card shell: use a darker preview surface, subtle hover affordance, and smaller responsive height.

Decisions

IDChoice · Rationale
D-001Use exportToSvg for inline cards. It crops to drawing bounds and removes editor chrome without a server renderer.
D-002Keep interactive Excalidraw behind open. Users still need pan/zoom/editable handoff without paying that UI cost in every card.

Tradeoffs

IDPicked over Rejected · Reason
T-001Client-side SVG export over a new backend render endpoint. The existing viewer already loads the scene and Excalidraw bundle.
