Decisions

IDChoice - Rationale
D-001Port with scoped CSS over runtime markup changes. Existing tests and event handlers already model the needed clickability.
D-002Keep <details> for tools. Native disclosure preserves keyboard behavior and open-state semantics.
D-003Remove production timeline spine and large header chrome. The assistant-ui mock reads as a flat thread with right-side state, not a vertical event log.
D-004Let the right inspector span the full desktop grid height and make mobile rail positioning static. This matches the mock pane while avoiding phone overlay.
D-005Group trace thinking and fold todo events in thread.js. Real runs produce noisy event streams that CSS cannot make assistant-ui-like.
