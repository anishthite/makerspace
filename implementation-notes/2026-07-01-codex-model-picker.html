Summary

Goal
Show openai-codex/* models after hosted Codex sign-in.
Source
User expects Codex sign-in to unlock picker choices and Pi SDK model selection.
Surface
GET /api/threads, GET /api/threads/:name, Pi defaults payload.
Schema
Reuse existing defaults.models array.
Auth
Use per-user openai-codex-auth in hosted mode.
Open Qs
0.

Algorithm

  1. Build a Pi AuthStorage from the signed-in user when hosted auth is required.
  2. Create ModelRegistry from that storage and read getAvailable().
  3. Feed those refs into existing configuredModelRefs().
  4. Pass user from thread list/detail routes into loadPiDefaults().
