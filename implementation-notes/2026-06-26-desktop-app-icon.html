Summary

Goal
Package Makerspace.app with makerspace.icns instead of electron.icns.
Source
public/logo-mark.svg.
Surface
npm run desktop:package, macOS bundle icon metadata, DMG artifact.
Schema
None.
Open Qs
0.

Algorithm

  1. Render public/logo-mark.svg as a temporary 1024×1024 PNG with sips.
  2. Downsample the PNG into the standard macOS .iconset sizes.
  3. Build makerspace.icns with iconutil and set CFBundleIconFile.
