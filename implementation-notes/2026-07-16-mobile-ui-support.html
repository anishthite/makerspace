Decisions

IDChoice · Rationale
D-001Use shadcn Sidebar mobile Sheet. The component already handles mobile drawer state and avoids a new navigation system.
D-002Use Tailwind responsive utilities for React-authored layout. The user explicitly asked to leverage existing responsive tools.
D-003Keep custom CSS for runtime/generated selectors. Thread cards, diff markup, and legacy tables are not all authored as Tailwind JSX.
D-004Re-render agents when Radix mounts mobile Sheet content. The sidebar DOM is absent while closed, so runtime code must tolerate late mount.
D-005Keep a throttled mount observer active. Mobile can render desktop-sidebar markup before matchMedia settles, so late Sheet mounts must still hydrate.
D-006Collapse non-JSON backend responses to a short unavailable message. Raw Vite HTML made mobile screenshots unreadable.

Tradeoffs

T-002Smoke check over screenshot diff suite.Horizontal overflow is the current failure and a cheap invariant.
