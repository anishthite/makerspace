UI layout

  1. Dialog: open as a modal lightbox over the project launcher when remote onboarding is incomplete and not dismissed.
  2. Checklist: show GitHub, Codex, repo/folder, and first-agent steps with live done states.
  3. Actions: reuse the existing GitHub sign-in handler, link Codex to /settings.html#codex, and focus the repo input.
