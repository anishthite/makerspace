Tracked agent changes

main · worktree /Users/anishthite/workspace/makerspace · 2026-06-25 · status shipped · blast low

Summary

Goal
Show files changed by agent edit and write tool events without running git diff.
Source
Live and persisted tool events keyed by toolCallId.
Surface
GET /api/threads/:name/diff, /thread.html, and thread SSE events.
Schema
Add optional session field trackedChanges.
Mobile
Reuse existing stacked changes box.
Open Qs
0; assume bash-side file mutations are not tracked until requested.

API contract

Response

{
  generatedAt: string,
  source: "tracked-tools",
  status: string,
  diff: "",
  files: [{ path: string, code: string, label: string, diff: string }],
  truncated: boolean,
  notGit: false
}

Algorithm

  1. Cache tool args from planning, planned, start, and update events by toolCallId.
  2. On successful end, create or replace one tracked file row for edit.path or write.path.
  3. Persist capped trackedChanges on the session so reloads do not need repo state.
  4. Render each file row's captured preview; do not parse the worktree.
