Decisions

IDChoice · Rationale
D-001Store light instead of dark. Missing browser storage should mean the new default.
D-002Use :root for dark tokens and html[data-theme="light"] for light tokens. First paint should not flash the old cream theme.
D-003Blend Tokyo Night and Catppuccin-style accents over a neutral dark base. The UI needs code-editor familiarity without copying one theme wholesale.
D-004Bust entrypoint cache strings. Old appearance.js would otherwise force unset sessions back to light mode.
