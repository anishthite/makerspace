Decisions

IDChoice · Rationale
D-001Cache loadPiDefaults for 30 seconds. Startup should not pay model registry and credential reads on every page poll.
D-002Parallelize existing browser requests first. Superseded by D-003 after baseline.
D-003Add GET /api/bootstrap. One request removes the project page's recent-projects-to-threads waterfall and collapses thread initial data into one response.

Tradeoffs

IDPicked over Rejected · Reason
T-001Small cache over new state layer. It avoids D1/API churn without migration risk.
T-002Bootstrap route over D1-specific batch reads. It cuts visible web RTT without binding the frontend to storage internals.
T-003Background repo loading over bundling GitHub repos into bootstrap. External GitHub latency should not block first paint.
