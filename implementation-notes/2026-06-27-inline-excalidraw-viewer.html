Decisions

IDChoice · Rationale
D-001Use a viewer iframe instead of embedding Excalidraw inside thread.js. It isolates the heavy React bundle from normal chat rendering.
D-002Keep viewer read-only. Pan/zoom/explore is requested; editing and save state can wait.
D-003Fetch only .excalidraw JSON through an authorized thread route. Avoid exposing arbitrary workspace files from static URLs.
D-004Viewer falls back to /artifacts/ static copies and treats non-JSON 404s as load misses. This keeps old public diagrams usable while the backend route is unavailable or stale.
D-005In dark mode, pass theme=dark to the viewer and replace default white Excalidraw canvases with #111827. Explicit non-white diagram backgrounds remain untouched.

Tradeoffs

IDPicked over Rejected · Reason
T-001CDN-loaded Excalidraw viewer over bundling. The app is static/no-bundler today and the existing renderer already uses esm.sh.
