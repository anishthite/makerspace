API contract

GET /api/auth/github
POST /api/auth/github/login
GET /api/auth/github/callback?code=...&state=...
POST /api/auth/github/logout
GET /api/github/repos?visibility=all
{
  configured: boolean,
  connected: boolean,
  loginUrl?: string,
  user?: { login: string, name: string|null },
  repos?: [{ id: number, fullName: string, cloneUrl: string, private: boolean, defaultBranch: string|null }]
}

Algorithm

  1. Start OAuth with backend-generated state; redirect browser to GitHub authorize URL.
  2. Exchange callback code for access token; save token and user metadata in backend settings.
  3. List repos from GET /user/repos; show them in the UI; use repo clone URL plus default branch when chosen.
  4. Pass repo auth metadata into stored thread session; clone private repos with git -c http.extraHeader instead of embedding the token in the URL.

Decisions

IDChoice · Rationale
D-001Use GitHub OAuth web flow over device flow. Matches the browser-first repo picker ask.
D-002Store the GitHub token in backend settings only. Keeps the browser token-free.
D-003Clone private repos with http.extraHeader over tokenized URLs. Avoids leaking tokens into stored repo URLs.
D-004Bypass CONTROL_API_TOKEN only for /api/auth/github/callback. GitHub cannot send the bearer token back.

Tradeoffs

IDPicked over Rejected · Reason
T-001Settings-backed single-user token storage over per-browser sessions. Matches the app's existing single-user settings model.
T-002Fetch repo list on demand over syncing all repo metadata into local files. Less state to own.

Assumptions

  • A-001 · This app stays single-user. If wrong: GitHub token storage needs per-user isolation.
  • A-002 · Sandboxes can reach github.com over HTTPS. If wrong: auth succeeds but clone still fails.

Reversibility

R-001 · medium. Revert UI and route changes; clear saved GitHub token fields from data/settings.json.

Definition of done

  • GitHub login connects from settings.html.

  • Creating a thread from a chosen repo uses the selected branch or default branch.
  • Private repo clones use auth without exposing the token in public session payloads.
  • npm test passes.
