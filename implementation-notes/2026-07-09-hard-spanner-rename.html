Algorithm

  1. On startup, if default ~/.spanner is absent and ~/.workbench exists, move the old directory to the new name.
  2. On D1 schema creation, create spanner_sessions/spanner_kv, then copy rows from old workbench_* tables when present.
  3. In browser runtime, copy old localStorage keys to new spanner* keys once and remove the old keys.
