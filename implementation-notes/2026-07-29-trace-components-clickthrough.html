UI layout

  1. Gallery toolbar: filter tool calls by all, running, errors, or open; expand/collapse every tool card.
  2. Trace summary: toggle the full trace groups from the run summary and header control.
  3. Diffs: click the diff rail to open a full diff preview overlay.
  4. Artifacts: toggle HTML artifact trusted/interact mode and show copy feedback.
  5. Workflow: select workflow nodes and reflect the selected agent in the rail header.
  6. Reference library: collapse call groups, shorten code output, copy the summary, select rows, and select changed files.
