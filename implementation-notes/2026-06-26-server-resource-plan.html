Decisions

IDChoice · Rationale
D-001Default PI_HOST_DISPATCH off. Terminal-first usage should not preload/run the Pi SDK on the control server.
D-002Read Pi defaults from settings instead of creating a throwaway agent session. Model-picker nicety should not import the full SDK on page load.
D-003Turn generated titles and final-answer summaries off by default. Extra LLM calls are optional UI polish.
D-004Replace idle SSE polling with event push. One open tab should not parse sessions.json ten times per second.
D-005Cap live output, tool output, thinking, and tracked-change buffers. Terminal output is live data, not permanent RAM ballast.
D-006Supersedes: D-003. Keep generated titles and final-answer summaries enabled, but run them through one delayed serialized low-priority queue.
D-007Use one Map<name, Set<subscriber>> for SSE push. Replay registers before enqueueing retained events so live events cannot slip between replay and subscription.
D-008Add baseOffset/nextOffset to retained output. Clients can recover from tail truncation without retaining infinite text in RAM.
D-009Make PI_HOST_DISPATCH explicit opt-in with PI_LOCAL_DISPATCH as a legacy truthy alias. Default server startup avoids Pi SDK preload.
D-010Return settings-derived Pi defaults from /api/threads. Rich SDK model discovery stays off the hot path.

Tradeoffs

IDPicked over Rejected · Reason
T-001Cheap caps and defaults over SQLite/Redis. The bottlenecks are obvious without adding infrastructure.
T-002Compact cached JSON store over per-session files. Avoid migration work until compact/cache is measured.
T-003Opt-in UI polish over always-on title/summary/model discovery. Terminal use values low RSS more than decoration.
T-004Queued polish over disabled polish. User constraint keeps UI finish while moving LLM calls off the run/create hot path.

Assumptions

  • A-001 · Terminal/local mode is the priority. If remote web latency is priority, keep host dispatch opt-in with PI_HOST_DISPATCH=1.

Reversibility

R-001 · medium. Defaults can be reverted or exposed as env toggles without data migration.

Definition of done

  • Title generation, summary generation, and model default discovery do not load Pi SDK on the run/create hot path.
  • Idle SSE clients do not cause repeated store reads while no events arrive.
  • Live output/tool/thinking/tracked-change buffers have documented byte/count caps.
  • npm test passes with one small regression test per touched hot path.
