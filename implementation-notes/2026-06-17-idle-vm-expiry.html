Summary

GoalDestroy reusable bridge VMs after one hour idle.
Surfacesrc/server.js cleanup loop and src/provider.js destroy command.
TTLIDLE_BRIDGE_TTL_MS=3600000 default.
StateRemove destroyed sessions from data/sessions.json.
Verificationnpm test passes.
Tagsmicro-cloud, exe.dev, bridge, cleanup, ttl

Algorithm

  1. Select sessions where bridgeMode, unclaimed, status=ready, and idle age exceeds idleBridgeTtlMs.
  2. Call provider.destroySession(name).
  3. Remove the session row after successful destroy.
  4. Run on startup and every idleBridgeTtlMs.
