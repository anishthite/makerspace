Summary

Goal
Serve the existing landing page at /homepage and redirect unsigned hosted users there.
Source
GET /api/me exposes authRequired, authenticated, and githubConfigured.
Surface
/homepage, /desktop.html, React entry bootstrap.
Schema
None.
Mobile
Existing landing breakpoint only.
Open Qs
0.

Algorithm

  1. Fetch /api/me through VITE_SPANNER_API_BASE during React bootstrap.
  2. If authRequired && !authenticated && githubConfigured, replace the current route with /homepage?returnTo=<current URL>.
  3. Keep local/dev routes in place when the auth API is unavailable or GitHub OAuth is not configured.
