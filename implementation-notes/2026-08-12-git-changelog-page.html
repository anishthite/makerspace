Summary

Goal
Publish /changelog.html from the repository’s release tags and non-merge commits.
Source
git tag and git log run by Vite while it builds the frontend.
Surface
/changelog.html and the virtual:spanner-changelog build module.
Schema
{ version, date, commits: [{ hash, shortHash, date, subject }] }.
Mobile
Stack release metadata and keep commit rows readable.
Open Qs
0.

Algorithm

  1. Read merged semantic-version tags in version order.
  2. Read non-merge commits between each adjacent tag, plus HEAD commits after the latest tag.
  3. Embed the release data into the Vite build and render it on /changelog.html.

UI layout

  1. Header: release page title, generation date, workspace link.
  2. Release list: version/date heading followed by commit subject, hash, and date rows.
