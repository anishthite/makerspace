API contract

Request

GET /api/threads/performance

Response

{
  provider: object,
  generatedAt: string,
  performance: {
    summary: { totalThreads, failedThreads, runningThreads, medianFirstLlmMs, p95FirstLlmMs, totalToolCalls, totalToolErrors },
    insights: string[],
    threads: ThreadPerformance[]
  }
}

Algorithm

  1. Filter visible threadBridge sessions with existing browser-session access rules.
  2. Use firstLlmLatencyMs, submittedAtMs, and updatedAt for stored metrics.
  3. Fold live tool, metric, status, and chunk events when present.

UI layout

  1. Hero stats: show counts, median/p95 first LLM, tool calls, and tool errors.
  2. Insights: list slowest latency, failed threads, and tool-error hotspots.
  3. Thread table: link each row back to /thread.html with latency, duration, tools, errors, and flags.
