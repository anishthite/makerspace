Final turn status classifier

main · worktree /Users/anishthite/workspace/makerspace · 2026-07-02 · status shipped · blast low

Summary

Goal
Color the latest assistant turn by whether the conversation is done or waiting on the human.
Source
User approved the classifier flow and suggested gpt-5.4-mini.
Surface
/thread.html assistant message dot/card plus stored thread metadata.
Schema
Add optional finalTurnStatus, finalTurnColor, finalTurnReason, finalTurnStatusRunId, finalTurnStatusModel, finalTurnStatusUpdatedAt.
Open Qs
0.

Algorithm

  1. After final assistant text persists, send previous user turn plus latest assistant turn to THREAD_TURN_STATUS_MODEL.
  2. Parse JSON into done|waiting_on_human|unknown and map to green|amber|gray.
  3. Store the result on the session and emit a turn_status event for refresh/live replay.
  4. Apply the color to the latest assistant message for the matching run id.
