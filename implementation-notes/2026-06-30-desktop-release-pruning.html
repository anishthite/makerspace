Algorithm

  1. Copy the app as before.
  2. Rewrite the packaged package.json to keep only backend/runtime dependencies.
  3. Delete the packaged package-lock.json before npm prune so old root dependencies do not stay pinned.
  4. Remove source maps, type declarations, markdown, docs, examples, and test folders from packaged node_modules.
