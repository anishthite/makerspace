→ { configured, source, expiresAt?, updatedAt? }

→ { id, status, auth: { url, instructions }, manual }

POST /api/auth/claude-code/login/:id/code
{ code }
→ { id, status, progress? }

GET /api/auth/claude-code/login/:id
→ { id, status, auth?, manual?, progress?, error? }

Algorithm

  1. Start Pi AuthStorage.login('anthropic') with manual-code callbacks.
  2. Show the returned Claude authorize URL in Settings and open it in a new web tab when possible.
  3. Let local callback complete automatically on the backend host.
  4. Let hosted website users paste the final localhost:53692 redirect URL or code.
  5. Store hosted credentials under claude-code-auth; render remote auth.json with both openai-codex and anthropic when present.
