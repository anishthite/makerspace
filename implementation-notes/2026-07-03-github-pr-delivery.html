GitHub PR delivery

main · /Users/anishthite/workspace/makerspace · 2026-07-03 · shipped · blast high

Summary

Goal
Backend commits tracked agent file paths, pushes with one-shot GitHub auth, and opens a draft PR.
Source
User request: authenticated commit/push and no git add -A.
Surface
POST /api/threads/:name/pull-request; GitHub thread creation defaults to deliveryMode: "draft-pr".
Auth
GitHub token stays in backend memory; sandbox receives only http.extraHeader for one push command.
Staging
Stage only normalized paths from session.trackedChanges plus live active-run tracked changes.
Blast
High: pushes branches and creates GitHub PRs.

API contract

POST /api/threads/:name/pull-request
{ "title"?: string, "body"?: string, "draft"?: boolean }

200
{
  "provider": object,
  "thread": object,
  "pullRequest": { "url": string, "number": number, "branch": string, "files": string[] } | null,
  "noChanges": boolean
}

Algorithm

  1. Merge stored and live trackedChanges; drop absolute paths outside remoteWorkspaceDir.
  2. Build shell script with an explicit Bash array of safe relative files.
  3. Run git status --porcelain -- "${files[@]}"; exit cleanly with noChanges when empty.
  4. Run git add -- "${files[@]}", commit, then push HEAD:refs/heads/makerspace/<thread> using git -c http.extraHeader=....
  5. Create a draft PR through GitHub API and persist prStatus, prUrl, prBranch, and staged files on the thread row.

Decisions

IDChoiceRationale
D-001Use tracked tool paths as the staging allowlist.Matches existing UI source and avoids collecting incidental sandbox changes.
D-002Create draft PRs only.Review-first default avoids shipping agent output directly.
D-003Use one endpoint plus automatic GitHub-thread delivery.Manual retry path covers auto-delivery failures without new job tables.
D-004Reuse the thread PR branch on follow-up runs.One open PR per thread keeps review state stable.

Tradeoffs

IDPicked over RejectedReason
T-001One-shot http.extraHeader over credential helpers.Prevents long-lived tokens on sandbox disk.
T-002Single branch per thread over per-run branches.Shortest branch model; force-with-lease makes retry overwrite intentional.

Assumptions

  • A-001: OAuth repo scope is sufficient for push and PR creation on selected repositories.
  • A-002: Tool-tracked changes are the desired commit contents; bash-created incidental files remain unstaged.

Reversibility

R-001: Revert src/git-delivery.js plus route/service edits to disable PR delivery; remote branches/PRs already created must be closed manually.
