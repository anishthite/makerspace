Summary

Goal
Make hosted pages stop paying remote auth/D1 latency for every static asset and repeated API poll.
Source

Decisions

IDChoice · Rationale
D-001Skip currentUser() entirely for non-API static requests; static HTML/JS/CSS should load before API auth gates.
D-002Cache current-user resolution briefly per auth session hash; repeated remote polls avoid serial auth-session + user reads.
D-003Cache D1 KV reads briefly, including misses without pinning caller fallbacks; auth status uses several KV keys per bootstrap.
D-004Move unsigned hosted redirects from a separate /api/me preflight into protected API failure handling; one startup API beats two serial calls.
D-005Add fast=1 bootstrap mode: return threads/recent projects first, then let Codex/GitHub status and thread output hydrate after first paint.
D-006Render cached workspace thread rows before the network refresh, but skip suggestion generation for stale cache paints.
