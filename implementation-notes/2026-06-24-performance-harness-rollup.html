Algorithm

  1. Update a compact rollup when metric, tool, log, chunk, warning, and status events arrive.
  2. Prefer live events for active runs; fall back to stored rollup; return nullable detailed counters when only latency is known.
  3. Use runEndedAtMs || endedAt || completedAt || updatedAt for finished durations.

Decisions

IDChoice · Rationale

D-002Represent missing detail as null. Zero must mean measured zero.
D-003Gate stored first-LLM latency to first_llm_call_start. Later metrics must not overwrite the primary harness number.
D-004Count output with Buffer.byteLength(..., 'utf8'). String length undercounts non-ASCII chunks.
