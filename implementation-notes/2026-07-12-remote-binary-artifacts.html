Remote binary artifacts

main · worktree /Users/anishthite/workspace/makerspace · 2026-07-12 · status shipped · blast medium

Summary

Goal
Make generated .png, .jpg, .gif, and .webp previews render for remote thread artifacts.
Source
User reports valid remote .png artifacts show broken-image alt text on main.
Surface
/api/threads/:name/artifacts/file, Cloudflare provider file reads, sandbox broker file route.
Schema
No stored data change; broker JSON adds optional encoding for file reads.
Open Qs
0; use base64 only for binary artifact reads.

Algorithm

  1. Thread image artifact reads request encoding=base64 from remote providers.
  2. Provider decodes { content, encoding:"base64" } into a Buffer before the route writes the response.
  3. Text artifact reads keep the existing UTF-8 path.

Decisions

IDChoice · Rationale
D-001Use Cloudflare sandbox readFile(...,{encoding:"base64"}). The SDK already supports binary-safe reads over the HTTP transport.
D-002Keep the browser route returning raw image bytes. Existing <img> and blob preview code need no frontend change.

Tradeoffs

IDPicked over Rejected · Reason
T-001Base64 broker JSON over streaming file bytes. Artifact previews are capped at 16 MiB, and this is the smallest compatible route fix.
