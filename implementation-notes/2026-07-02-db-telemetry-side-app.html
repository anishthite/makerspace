Algorithm

  1. Load accessible threadBridge sessions from the existing store.
  2. Compute recency, success, coverage, top repo/tool/model, latency, duration, token, and cache rollups from stored/live summaries.
  3. Render unknown values as — instead of inventing analytics.

UI layout

  1. Hero: label the view as telemetry and state that it is estimated from the session DB.
  2. Stats: show total, recent, status, success, latency, tools, and usage counters.
  3. Side panel: list what the DB can and cannot tell us without adding tracking.
