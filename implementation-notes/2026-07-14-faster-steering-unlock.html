Faster steering unlock

main · worktree /Users/anishthite/workspace/makerspace · 2026-07-14 · status ready-for-review · blast medium

Summary

Goal
Let users send steering/follow-up messages during bridge starting/queued once the remote run exists.
Source
User wants steering unlock much faster.
Surface
POST /api/threads/:name/messages, generated bridge POST /runs, /thread.html composer.
Schema
None; pending delivery stays in remote bridge memory.
Mobile
Untouched.
Open Qs
0.

Algorithm

  1. Host accepts active bridge delivery for queued, starting, and running.
  2. Bridge stores delivery messages in a per-run memory queue until run.child exposes steer/followUp.
  3. Bridge starts piSession.prompt(), flushes queued delivery, then awaits the prompt result.
  4. Composer enables the button for claimed remote bridge runs in queued/starting.
