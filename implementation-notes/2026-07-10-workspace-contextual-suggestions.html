Summary

Goal
Make /workspace.html starter prompts feel specific instead of generic.
Source
User asked for main-page suggested inputs to be as unique and helpful as thread suggestions.
Surface
#launch-suggestions below the workspace composer.
Schema
No API or stored data change; reuse thread.suggestedNextSteps.
Fallback
Keep three static prompts when no recent thread suggestions exist.

Algorithm

  1. Load workspace threads from /api/threads.
  2. Sort inactive threads by finishedAtMs descending.
  3. Take up to three unique suggestedNextSteps[].prompt values.
  4. Render dynamic labels and exact prompts into #launch-suggestions; restore initial HTML when empty.

UI layout

  1. Fallback chips: show more concrete starter prompts on first paint.
  2. Context chips: replace fallback chips with recent generated thread prompts after threads load.
  3. Composer: keep click-to-fill behavior unchanged.
