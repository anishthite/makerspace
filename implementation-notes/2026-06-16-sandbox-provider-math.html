Assumptions

  • A-001 · Cloudflare basic uses 0.25 vCPU; closest 1-vCPU comparison is standard-2.
  • A-002 · exe.dev short burst cost uses an opened hour because CPU and active memory are priced by hourly peak usage.
  • A-003 · Daytona default 3 GiB disk falls under the first 5 GB free storage line.
  • A-004 · Daytona pricing page read 2026-06-18 lists $0.0504/vCPU-hour, $0.0162/GiB RAM-hour, and $0.000108/GiB disk-hour after first 5 GiB.
  • A-005 · src/provider.js sends custom resources only when imageRef or DAYTONA_IMAGE selects an image; snapshot/default launches omit resources.
  • A-006 · Stopped sandboxes stop CPU/RAM billing and retain only billable disk until autodelete.
  • A-007 · Model-provider token spend is outside Daytona sandbox cost.
  • A-008 · Original guide used a 720h month; the 2026-06-18 Daytona quick estimate used 730h.
