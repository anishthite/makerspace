Open Qs
0.

Algorithm

  1. Parse each JSONL source with stdlib JSON and extract only human-visible user/assistant text.
  2. Skip Claude subagent journals and tool-result-only user entries because they are agent-generated, not human follow-ups.
  3. For each consecutive human user pair, emit the recent visible context before the later user as context_messages and the later text as next_user_message.
  4. Dedupe examples by message content hash and write counts plus skipped lines to manifest.json.

Decisions

IDChoice · Rationale
D-001Emit full local text, not redacted text. The user asked for a dataset to train suggestions later.
D-002Keep a tiny Python extractor in the dataset folder. Stdlib handles JSONL and SQLite path discovery is unnecessary for the current source files.
D-003Use context_messages plus next_user_message. Suggestion models need the assistant answer that triggered the follow-up.
D-004Filter injected AGENTS.md, interrupted-turn, and Codex apply-patch warning user records. They are harness artifacts, not human next messages.
D-005Add omitted_context_messages and context_char_trimmed. A boolean alone hid whether messages or text were shortened.

T-002Consecutive human-message pairs over every event transition. Tool chatter is not the prediction target.
