IDChoice · Rationale
D-001Keep the existing ssh provider flow. The app already provisions remote VMs; the problem is UI focus, not transport.
D-002Drop the exe.dev-vs-VPS report from the homepage. The user asked to use pi on exe.dev, not compare hosting options.
D-003Derive https://<vm>.exe.xyz/ when a session has no explicit httpsUrl. exe.dev proxies that host by default.
