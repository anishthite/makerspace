Summary

Goal
Close Spanner-created local worktrees on archive and recreate them on unarchive.
Source
Conductor archives workspaces by saving git state, running archive cleanup, and removing the worktree.
Surface
POST /api/threads/:name/archive, POST /api/threads/:name/unarchive, local Git helpers.
Schema
Add session metadata worktreeClosedAt, worktreeRestoredAt, worktreeArchiveStash, worktreeArchiveStashAppliedAt.
Mode
Only local Spanner-created worktrees; skip reused/shared worktree paths.
Open Qs
0.

Algorithm

  1. Archive validates terminal status, then targets sessions with localMode && localWorktree && !reuseRepoPath.
  2. If the worktree has tracked or untracked changes, run git stash push -u from the worktree and record the stash hash.
  3. Run git worktree remove --force <worktreePath> from sourceRepoPath; fail archive if Git refuses.
  4. Unarchive recreates a missing worktree from worktreeBranch || worktreeBaseRef || branch || HEAD and reapplies the recorded stash once.

Decisions

IDChoice · Rationale
D-001Archive owns worktree removal. It matches Conductor's close point.
D-002Skip reuseRepoPath. A reused worktree can host multiple threads or be user-owned.
D-003Use git stash push -u before removal. It preserves normal git state without committing agent work.

Tradeoffs

IDPicked over Rejected · Reason
T-001Stash tracked/untracked files over force-only deletion. It avoids deleting reviewable work.
T-002Leave branch deletion out. Spanner lacks Conductor's delete_branch_on_archive setting and branch deletion would break restore.
T-003Local-only over remote workspace cleanup. Remote durable workspaces need provider scripting and restore semantics.
