Summary

Goal
Remote sandboxes stop receiving GitHub OAuth tokens that GitHub rejects for .github/workflows/* writes.
Surface
/api/auth/github/login, /api/auth/github, sandbox auth sync.
Auth
Request workflow; mark old OAuth tokens as reconnect-required for remote git.
Open Qs
0.

Algorithm

  1. Authorize with repo read:user workflow.
  2. Persist the requested scope list with the OAuth token.
  3. Return no sandbox OAuth token when stored scopes miss workflow; GitHub App tokens still win.
  4. Show Settings reconnect copy when an old stored token misses required remote-git scopes.
