Decisions

IDChoice · Rationale
D-001Use a Pi package plus SDK DefaultResourceLoader additional paths. This avoids overwriting user dotfiles.
D-002Make the package local-first. DMG and baked images can load the exact same directory before npm publication.
D-003Inject instructions from an extension. Pi packages do not install AGENTS.md as a first-class resource.

Tradeoffs

IDPicked over Rejected · Reason
T-001Additional resource paths over mutating settings.json. User package settings remain theirs.
T-002Baked local remote package over remote upload plumbing. The current remote happy path already supports custom images.
