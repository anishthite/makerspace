UI layout

  1. Default card: keep a script-blocked sandboxed iframe and label it sandboxed.
  2. Trust action: add one interact button that reloads the iframe with interaction permissions.
  3. Focused frame: focus the iframe on enable, load, and hover so arrow keys land in the demo.

Decisions

IDChoiceRationale
D-001Use per-frame interact opt-in.Default artifact previews keep the safer sandbox path.
D-002Do not add allow-same-origin.Pointer, wheel, keyboard, and CDN module imports work without letting arbitrary artifact HTML share Spanner origin.
D-003Inject a tiny keyboard-target shim only in trusted mode.Sandboxed frames focus the document body, while demos like flip-concepts.html listen on the hovered .demo node.
