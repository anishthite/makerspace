Decisions

IDChoice · Rationale
D-001Allow same-origin relative/root/hash/query hrefs. These are browser routes, not filesystem reads.
D-002Allow bare loopback dev URLs by adding http://. Local server links are common in agent output.
D-003Keep file://, protocol-relative, and JavaScript-like schemes blocked. Message text must not open arbitrary local files or scripts.
D-004Auto-link bare repo-relative paths only when they end in a known artifact/file extension. Generic slash words stay plain text.

Tradeoffs

IDPicked over Rejected · Reason
T-001Markdown local hrefs plus conservative bare local patterns over auto-linking every path. File-path false positives stay lower.

Assumptions

  • A-001 · Local means same-origin app/preview paths and loopback dev URLs. If wrong: widen the allowlist with a new decision entry.
