agent message concepts

Four ways to make the agent feel alive.

Static HTML only. I ran the current agent page first; it has a solid centered timeline, but reloads can feel empty because the prompt, answer, work, and status are not grouped into durable turns.

best bet
Turn Cards: one prompt, one answer, one collapsible work trail.
live run
Split Stream: conversation stays readable while tools update beside it.
memory
Notebook: best for reviewing how an agent evolved.
wild card
Pulse Deck: current answer becomes the hero; activity is peripheral.
