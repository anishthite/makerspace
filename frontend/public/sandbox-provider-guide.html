sandbox provider

Daytona is the runtime provider for workbench.

The control backend uses @daytona/sdk to create sandboxes, run setup commands, manage files, and expose the Pi bridge through preview URLs.

Provider responsibilities

  • Lifecycle: create, list, stop/delete, and apply idle lifecycle intervals.
  • Bridge access: call getPreviewLink(port) and send the preview token only from the backend.
  • Execution: run setup, direct Pi, log polling, and host-dispatch commands through Daytona process APIs.
  • Files: route host-dispatch read/write/edit operations through Daytona filesystem APIs.
