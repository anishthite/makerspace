Cloudflare Sandboxes are the runtime provider for Spanner.

The Node backend talks to a Cloudflare Worker broker. The broker owns @cloudflare/sandbox, Durable Objects, the container image, exposed bridge ports, and R2-backed backups.

  • Lifecycle: create, backup, restore, and destroy through the broker.
  • Execution: run setup, direct Pi, log polling, and host-dispatch commands through broker exec.
  • Files: route host-dispatch read/write/edit operations through broker file APIs.
  • Bridge: expose the Pi bridge port through Cloudflare sandbox URLs or tunnels.
