Five ways to make notes less ugly.

Same four notes, five layouts. No app behavior changed here — this is a static pick-sheet.

My lazy default: pick option 2 if notes should be read, option 1 if they only need to be spotted. The current green blocks are doing neither cleanly.

01

Ledger rows

Turns notes into a real index: title first, path second, metadata aligned.

best for scanning
  • Keeps the current compactness.
  • Stops long paths from eating the row.
  • Cheapest to ship.
