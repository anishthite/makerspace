Local should use your computer. Cloud should use Cloudflare Sandboxes.

Keep one browser UI and one backend API, then swap only the infrastructure provider: local uses git worktrees and local bridge processes; cloudflare uses the Worker broker, sandbox backups, and exposed bridge URLs.

INFRA_PROVIDER=local npm start
INFRA_PROVIDER=cloudflare npm start

Provider contract

  • createSession(): local creates worktree + bridge; Cloudflare creates sandbox + bridge.
  • destroySession(): local kills process + removes worktree; Cloudflare destroys sandbox.
  • runRemoteScript(): local runs shell in worktree; Cloudflare runs shell in sandbox.
  • readRemoteFile()/writeRemoteFile(): local reads mapped files; Cloudflare uses broker file APIs.
  • bridgeHeaders(): local returns none; Cloudflare can forward bridge bearer auth.
